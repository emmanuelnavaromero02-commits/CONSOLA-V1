# Copilot / MCP Threat Model

Status: required for v1.0 public readiness.

Scope: Console Copilot, MCP Infra tools, cartridge MCP calls, Refinement SQL,
Vault, Airflow, Superset, and RAG.

## Trust Boundaries

- User/browser input is untrusted.
- LLM output is untrusted, even when generated by an approved provider.
- MCP tool arguments are untrusted until validated server-side.
- Vault values and external cartridge credentials are secrets.
- Tenant/workspace/user scope must be enforced by server context and database
  guards, not by prompts.
